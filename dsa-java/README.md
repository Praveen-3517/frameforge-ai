## 🛠️ Repository Structure Standard
Each topic folder follows a consistent architecture:
```
<topic-folder>/
├── README.md           # Comprehensive conceptual notes, syntax, edge cases & best practices
├── easy/               # Foundational interview problems (TCS, Infosys, Wipro, Accenture)
├── medium/             # Core DSA & optimization problems (Amazon, Microsoft, Product Startups)
└── hard/               # Advanced algorithmic puzzles & bit-level trade-offs (Google, Meta, Directi)
```

Each Java solution contains:
- Detailed Problem Statement
- Company Tags (where asked)
- Step-by-Step Approach Explanation
- Working, fully compilable Java code with `public static void main(String[] args)`
- Comprehensive Test Inputs and Assertions
- Time Complexity and Space Complexity Analysis
